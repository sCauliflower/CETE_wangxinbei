# WTA 毁伤概率矩阵与目标价值向量 公式规范

> 输入：装备参数库（武器 / 飞机 / 舰艇 / 传感器）+ 想定场景态势。
> 输出：毁伤概率矩阵 
>
> $P=[p_{ij}]$
>
> （
>
> $n\times m$
>
> ）与目标价值向量 
>
> $V=[v_j]$
>
> （
>
> $1\times m$
>
> ）。

## 1. 符号定义



| 符号                    | 维度  | 含义                                          |
| --------------------- | --- | ------------------------------------------- |
| $W=\{w_1,\dots,w_n\}$ | $n$ | 红方武器 / 防御装备集合（矩阵**行**）                      |
| $T=\{t_1,\dots,t_m\}$ | $m$ | 蓝方目标集合（矩阵**列**）                             |
| $p_{ij}$              | 标量  | 武器 $i$ 对目标 $j$ 的**单发毁伤概率**，综合武器性能、目标防护、作战环境 |
| $v_j$                 | 标量  | 目标 $j$ 的价值，威胁越高价值越大                         |



* 矩阵元素为单武器对单目标概率；多武器齐射累积在分配阶段按独立事件并集计算：$P_{\text{kill},j}=1-\prod_{i\in A_j}(1-p_{ij})$，$A_j$ 为分配给目标 $j$ 的武器集合。

* $p_{ij}=0$ 表示类型不符或超出射程，不可交战。

## 2. 依据分层



| 层级            | 含义                                   | 标注       |
| ------------- | ------------------------------------ | -------- |
| **A. 公开标准公式** | 概率论、雷达 / 弹道教材、ITU、Swerling 等可公开复算的公式 | 【出处】     |
| **B. 库内标定值**  | 装备库给定的命中率、射程、DP、RCS、CEP、吨位、年份等，直接取用  | 【库值】     |
| **C. 工程衔接假设** | 标准公式与库值间缺公开闭环时所设分段 / 权重 / 系数，自编待校准   | 【假设・待校准】 |

A 层公开出处：Skolnik《Radar Handbook》、Kraus 天线理论、ITU-R P.834-6 视距、Swerling RM-1217 起伏检测、CFR 15 §772.1 CEP 定义、独立事件并集公式。

## 3. 输入参数字段映射

### 3.1 武器 $w_i$



| 变量                  | 库字段                              | 说明                         | 层级 |
| ------------------- | -------------------------------- | -------------------------- | -- |
| 类型命中率 $h_{i,t}$     | `basic.对空/对海/对陆/对潜命中率`           | 按目标类别选取，% 转 0–1；为 0 即不能打该类 | B  |
| 最大射程 $R_{\max,i}$   | `basic.对空/对海/对陆/反潜射程`            | 取区间上限（海里 nm）               | B  |
| 战斗部毁伤量 $W_i$        | `warhead` dict 数值                | 毁伤 DP / 装药质量，键名标类型         | B  |
| 精度 $\mathrm{CEP}_i$ | `basic.CEP,Surface` / `CEP,Land` | 米，近失折减用                    | B  |
| 发射包络                | `basic.发射高度` / `发射速度` / `目标速度`   | 包络判定 $f_E$                 | B  |

### 3.2 目标 $t_j$



| 变量              | 库字段                                           | 说明           | 层级  |
| --------------- | --------------------------------------------- | ------------ | --- |
| 损害点数 $DP_j$     | `basic.损害点数(DP)` / 顶层 `dp`                    | 生存力 / 体量主参数  | B   |
| 角色类型            | `basic.类型` / `basic.类别` / `type`              | 映射角色系数 $R_j$ | B+C |
| 服役年份 $Y_j$      | `basic.服役年份` / 顶层 `year`                      | 代次系数 $G_j$   | B   |
| 机动过载 $g_j$      | 飞机 `basic.机动性`；舰艇取 0                          | 机动修正 $f_G$   | B   |
| 目标特征 $\sigma_j$ | `signatures` RCS / 红外 / 目视距离（front/side/rear） | 被探测与防护修正     | B   |
| 幅员 $L_j$        | 舰艇吨位；飞机机体大小 / 长度                              | 易损性、近失折减     | B   |

> 平台 id 在飞机 / 舰艇 / 潜艇三类间可重复，回填必须按类别分库查询，不可合并字典。

### 3.3 态势变量（来自想定场景）



| 变量            | 含义                    | 来源                      |
| ------------- | --------------------- | ----------------------- |
| $d_{ij}$      | 武器 $i$ 与目标 $j$ 距离（nm） | 双方坐标 $(x,y,h)$ 三维欧氏距离换算 |
| 干扰状态 $J_{ij}$ | 电子对抗态势                | 想定标注                    |
| 目标方位          | 迎头 / 侧向 / 尾追          | 想定标注，取对应 RCS 方位         |

距离换算：$d=\sqrt{\Delta x^2+\Delta y^2+\Delta h^2}/1852$（米转 nm）。

## 4. 毁伤概率公式

### 4.1 顶层合成

$p_{ij}=
\begin{cases}
0, & \text{类型不符 或 } d_{ij}>R_{\max,i}\\[4pt]
\mathrm{clip}\Big(Pk_{0,i}\,f_R(\rho_{ij})\,f_T(j)\,f_G(j)\,f_J(ij)\,f_E(ij)\,f_K(i,j),\ p_{\min},\ p_{\max}\Big), & \text{否则}
\end{cases}
$



| 因子               | 含义          | 层级 | 定义  |
| ---------------- | ----------- | -- | --- |
| $Pk_{0,i}$       | 武器基准命中效能    | B  | 4.2 |
| $f_R(\rho_{ij})$ | 距离 - 射程比衰减  | C  | 4.3 |
| $f_T(j)$         | 目标防护 / 易损系数 | C  | 4.4 |
| $f_G(j)$         | 目标机动过载修正    | C  | 4.5 |
| $f_J(ij)$        | 干扰 / 电子对抗修正 | C  | 4.6 |
| $f_E(ij)$        | 发射包络 / 环境修正 | C  | 4.6 |
| $f_K(i,j)$       | 命中后毁伤系数     | C  | 4.7 |

截断边界缺省 $p_{\min}=0.01$、$p_{\max}=0.99$；门控失败严格取 0。

### 4.2 基准命中效能 $Pk_0$【B】

$Pk_{0,i}=\frac{h_{i,\text{type}(j)}}{100}$

飞机 / 直升机取对空，水面舰取对海，地面取对陆，潜艇取对潜；库命中率为 0 判门控失败。

### 4.3 距离衰减因子 $f_R(\rho)$【C，分段线性、可逆】

射程比 $\rho_{ij}=d_{ij}/R_{\max,i}$：

$f_R(\rho)=
\begin{cases}
1.00, & \rho\le 0.50\\[3pt]
1.00-0.80\,\dfrac{\rho-0.50}{0.30}, & 0.50<\rho\le 0.80\\[6pt]
0.20-0.15\,\dfrac{\rho-0.80}{0.20}, & 0.80<\rho\le 1.00\\[6pt]
0, & \rho>1.00
\end{cases}$

拐点 0.50 / 0.80 / 1.00 为经验取值，待按命中率 - 射程曲线标定。

### 4.4 目标防护 / 易损系数 $f_T$【C】



| 目标类别                   | $f_T$ |
| ---------------------- | ----- |
| 战斗机 / 攻击机 / 无人机        | 1.00  |
| 轰炸机 / 预警机 / 加油机 / 电子战机 | 0.90  |
| 直升机                    | 0.85  |
| 护卫舰 / 轻护 / 导弹艇         | 0.80  |
| 驱逐舰 / 巡洋舰              | 0.60  |
| 大型舰艇 / 航母              | 0.45  |
| 潜艇                     | 0.50  |
| 地面软目标（雷达站 / 营地）        | 0.95  |
| 地面硬目标（加固指挥所 / 机堡）      | 0.40  |

隐身目标可在 $f_T$ 上乘 $[0.7,1.0]$ 的 RCS 折减，按 RCS 档标定。

### 4.5 机动过载修正 $f_G$【C】



| 目标过载 $g_j$ | $f_G$ |
| ---------- | ----- |
| $g<5$      | 1.00  |
| $5\le g<7$ | 0.85  |
| $7\le g<9$ | 0.70  |
| $g\ge 9$   | 0.50  |

舰艇 $g=0$，$f_G=1.00$。

### 4.6 干扰修正 $f_J$ 与包络 / 环境修正 $f_E$【C】

$f_J$：



| 干扰态势        | $f_J$ |
| ----------- | ----- |
| 无干扰         | 1.00  |
| 目标自卫干扰 / 诱饵 | 0.70  |
| 敌方 ECM 压制   | 0.30  |
| 强压制 / 致盲    | 0.10  |

$f_E$：包络内 1.00；高度 / 速度在包络外取 0.5；目标速度超武器上限取 0.6；完全不可发射取 0。地形、气象、水文缺省取 1.00。

### 4.7 命中后毁伤系数 $f_K$【C】

毁伤比 $\kappa_{ij}=W_i/DP_j$：

$f_K(i,j)=C_{\text{type}}(i)\,C_{\text{target}}(j)\,\min\!\left(1,\ 0.5\sqrt{\kappa_{ij}}\right)$



* $C_{\text{type}}$ 战斗部类型适配：HE / 破片对空 1.00、对舰 0.70；半穿甲 / 穿甲对舰 1.00。

* $C_{\text{target}}$ 目标易损：战机 1.00、轻护 0.80、驱逐舰 0.60、大型舰 0.45、潜艇 0.50、地面硬目标 0.40。

* 形状因子 $0.5\sqrt{\kappa}$ 与各系数为经验值，待回放标定。

> 若口径为 "命中概率" 而非 "摧毁概率"，令 
>
> $f_K\equiv1$
>
> ，矩阵即退化为命中概率矩阵；口径在数据集元数据注明。

## 5. 目标价值公式

### 5.1 顶层公式

综合得分 $z_j\in[0,1]$，线性映射到价值区间 $[v_{\min},v_{\max}]
$：

$z_j=\mathrm{clip}\Big(w_{DP}S_{DP,j}+w_R R_j+w_G G_j+w_T Th_j-w_C C_{\text{cov},j},\ 0,\ 1\Big)
$

$v_j=v_{\min}+(v_{\max}-v_{\min})\,z_j$

缺省权重：$w_{DP}=0.35,\ w_R=0.45,\ w_G=0.20,\ w_T=0.10,\ w_C=0.00$。$v_{\min},v_{\max}$ 为场景配置的价值上下界。

### 5.2 生存力分 $S_{DP}$【C 对数归一】

$S_{DP,j}=\frac{\ln(1+DP_j)}{\ln(1+DP_{\max})}$

$DP_{\max}$ 为本场景目标 DP 最大值。

### 5.3 角色 $R_j$、代次 $G_j$、特殊威胁 $Th_j$

**角色系数&#x20;****&#x20;**（按类型 / 名称关键词判定）：



| 角色                    | $R$       |
| --------------------- | --------- |
| 预警机 / 指挥机 / 电子战机 / 侦察 | 1.00      |
| 加油机 / 反潜指挥            | 0.80      |
| 轰炸机 / 反舰导弹载机          | 0.75      |
| 战斗机 / 攻击机 / 无人机       | 0.60      |
| 直升机                   | 0.40      |
| 航母 / 两栖攻击舰            | 1.00      |
| 巡洋舰 / 驱逐舰             | 0.70      |
| 护卫舰 / 轻护              | 0.50      |
| 潜艇                    | 0.60–0.75 |
| 地面雷达站 / 指挥所 / 防空阵地    | 0.70      |
| 普通地面单位 / 设施           | 0.30      |

**代次系数&#x20;****&#x20;**：

$G_j=0.5+0.5\,\frac{Y_j-Y_{\min}}{Y_{\max}-Y_{\min}}$

$Y$ 取服役年份，$Y_{\min}/Y_{\max}$ 为本场景年份极值；缺年份取中性 0.5。

**特殊威胁&#x20;****&#x20;**：承担预警、指挥、引导打击、反辐射、电子战等关键功能的节点取 1.0，普通平台取 0.0，从类型 / 能力关键词判定。

### 5.4 覆盖度校正项 $C_{\text{cov}}$（可选，默认关闭）

$c_j=\frac{\#\{i:p_{ij}>0\}}{n},\qquad C_{\text{cov},j}=\frac{c_j-c_{\min}}{c_{\max}-c_{\min}}$

$w_C$ 缺省 0.00。是否启用及折减方向由想定意图标定：进入己方火力扇区、被多件武器覆盖的目标可做负向折减；突防近距、仅少数武器可拦的目标方向取反。

### 5.5 价值与命中的一致性

高角色 / 高特殊威胁目标通常配强防护、高机动，在 4.4 / 4.5 取更小的 $f_T/f_G$，使其单发毁伤概率偏低；价值高低与命中难易通过同一套目标属性联动。

## 6. 反推链路

### 6.1 由 $p_{ij}$ 反解距离

已知武器、目标及其余因子，先反解距离衰减因子：

$\hat f_R=\frac{p_{ij}}{Pk_{0,i}\,f_T(j)\,f_G(j)\,f_J(ij)\,f_E(ij)\,f_K(i,j)}$

按 4.3 分段逆函数解 $\rho$：



| $\hat f_R$ 所在段       | 反解 $\rho$                                     |
| -------------------- | --------------------------------------------- |
| $=1.00$              | $\rho\in[0,0.50]$（近距平坦段，仅知 $d\le0.5R_{\max}$） |
| $0.20<\hat f_R<1.00$ | $\rho=0.50+0.30(1.00-\hat f_R)/0.80$          |
| $0<\hat f_R\le0.20$  | $\rho=0.80+0.20(0.20-\hat f_R)/0.15$          |
| $=0$                 | 门控失败：类型不符或 $d>R_{\max}$                       |

距离 $\hat d=\rho\,R_{\max,i}$。

### 6.2 由 $p_{ij}$ 反解基准命中率

已知距离 $d_{ij}$（即已知 $\rho$ 与 $f_R$）及其余因子：

$\widehat{Pk}_{0,i}=\frac{p_{ij}}{f_R(\rho_{ij})\,f_T(j)\,f_G(j)\,f_J(ij)\,f_E(ij)\,f_K(i,j)}$

同一武器跨多个目标的反解值取中位，平滑目标侧噪声。

### 6.3 由 $v_j$ 反解价值分量

$\hat z_j=\frac{v_j-v_{\min}}{v_{\max}-v_{\min}}$



* 生存力反解 DP：$DP_j=\exp\!\big(S_{DP}\ln(1+DP_{\max})\big)-1$。

* 代次反解年份：$Y_j=Y_{\min}+2(G_j-0.5)(Y_{\max}-Y_{\min})$。

* 覆盖度由矩阵列直接回算：$c_j=\#\{i:p_{ij}>0\}/n$。

价值为线性加权，分量间存在混叠；单个 $v_j$ 不能分离各分量，需先由库内已知角色、年份、DP 固定若干项，再反解剩余项。

### 6.4 闭合校验

正算 → 反解 → 再正算应闭合；反解距离 / 命中率 / DP / 年份与原始参数偏差超阈值（距离 >10%、命中率跨档）则回查因子标定。

## 7. 数值算例

### 7.1 毁伤概率

空空弹 $Pk_0=0.80$、$R_{\max}=50$ nm；目标战机 $g=7$，无干扰、包络内，$f_K=0.90$；$d=30$ nm。



* $\rho=30/50=0.60$，$f_R=1.00-0.80(0.60-0.50)/0.30=0.7333$。

* $f_T=1.00$，$f_G=0.70$，$f_J=1.00$，$f_E=1.00$。

* $p=0.80\times0.7333\times1.00\times0.70\times1.00\times1.00\times0.90=0.3696$。

反推：$\hat f_R=0.3696/(0.80\times1.00\times0.70\times1.00\times1.00\times0.90)=0.7333$；$\rho=0.50+0.30(1-0.7333)/0.80=0.60$；$\hat d=0.60\times50=30$ nm，闭合。

### 7.2 目标价值

驱逐舰 $DP=650$，$DP_{\max}=1270$；$R=0.70$；$Y=1985$，$Y_{\min}=1980,Y_{\max}=2010$；$Th=0$，$C_{\text{cov}}=0$。



* $S_{DP}=\ln(651)/\ln(1271)=0.906$；$G=0.5+0.5(1985-1980)/30=0.583$。

* $z=0.35\times0.906+0.45\times0.70+0.20\times0.583=0.749$。

* $v=v_{\min}+(v_{\max}-v_{\min})\times0.749$。

反推：$\hat z=(v-v_{\min})/(v_{\max}-v_{\min})=0.749$；$Y=1980+2(0.583-0.5)(30)=1985$，闭合。

## 8. 待校准清单



1. $f_R$ 拐点、$f_T/f_G$ 档位、$f_J$ 档位、$f_K$ 形状因子与系数表、价值权重、$v_{\min}/v_{\max}$、隐身 RCS 折减，均为 C 层初始经验值，需回放数据标定。

2. 战斗部装药质量与目标 DP 的量纲对齐缺公开标准闭环，$\kappa$ 比例系数必须回放标定。

3. 库内成本字段基本为空，价值为属性代理排序分；如需货币口径另接公开采购价库。

4. $f_R$ 近距平坦段、价值线性加权混叠处反推不唯一，需外部约束补全。

## 9. 落盘字段

概率长表（每对一行）：



```
scenario_id, weapon_id, weapon_name, target_id, target_name,
target_type, distance_nm, Rmax_nm, rho, Pk0, fR, fT, fG, fJ, fE, fK, p_ij, qty
```

价值长表（每目标一行）：



```
scenario_id, target_id, target_name, DP, S_DP, R, G, Th, C_cov, z_j, v_j, v_norm
```

矩阵由长表按 `(weapon_id, target_id)` 透视还原；元数据注明概率口径（毁伤 / 命中）、价值区间、所用 C 层系数版本。
